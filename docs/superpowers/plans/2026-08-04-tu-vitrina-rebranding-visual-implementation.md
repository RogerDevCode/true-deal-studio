# Tu Vitrina Rebranding and Visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the public STAX Web experience into Tu Vitrina on `tuvitrina.lat`, with useful local imagery and an audible VoiceLive proof that demonstrates a real assistant response.

**Architecture:** Keep the static, `file://`-compatible site architecture. Brand values and public URLs change in HTML, SEO metadata, JSON-LD, legal pages and user-facing copy; internal selectors remain stable unless their related tests change at the same time. Add a small local asset set for visual context, and replace the hero video proof with a local `<audio>` proof whose transcript is available only when needed for accessibility.

**Tech Stack:** Static HTML, local CSS/Tailwind output, Alpine.js, local WebP assets, Ogg/MP3 audio, WebVTT, Node.js 22, Playwright.

## Global Constraints

- Preserve the existing uncommitted `voice.tuvitrina.lat` link changes and update their tests together.
- Keep all resources local and all relative demo paths explicit for `file://` compatibility.
- Visible brand, public metadata, JSON-LD, forms and public URLs use **Tu Vitrina** and `tuvitrina.lat`; internal test IDs may retain `stax` where changing them has no public value.
- Do not claim real clients, guaranteed sales, live human attention, or unverified results.
- One contextual visual at most per page decision point; no carousels, autoplay, remote images, visual-only text, or decorative repetition.
- The audio proof is manually initiated, generated by VoiceLive from approved information, and includes an optional accessible transcript.
- Keep a single `h1`, visible focus, contrast, reduced-motion behavior, responsive layout and offline resources on every public page.
- Do not expose secrets, modify DNS/Cloudflare/OAuth, or create a Git commit unless the user explicitly requests it.

## File Structure

- `index.html`: primary brand, SEO/JSON-LD, Tu Vitrina hero and audible VoiceLive proof.
- `privacidad.html`, `terminos.html`: legal page brand, titles and public references.
- `demo-*/index.html`: visible demo boundaries, return links, proposal metadata and one contextual image only where the page currently has none.
- `assets/visuals/tu-vitrina-*.webp`: new local contextual images, organized by use rather than business name.
- `assets/visuals/tu-vitrina-voice-answer.{ogg,mp3,vtt}`: local assistant response and accessible transcript.
- `tests/*.spec.js`, `scripts/preproduction_gate.js`, `scripts/production_smoke.js`: updated contracts for brand, domain, audio proof and public titles.
